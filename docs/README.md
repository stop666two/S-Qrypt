# docs 目录

项目内文档只放**可复核的结论**，实现细节以代码与 `git log` 为准。

| 文件 | 内容 | 何时读 |
|---|---|---|
| `review/2026-11-21-full-review.md` | 全面审查报告：28 条发现（1 阻断 / 6 高危 / 其余按严重度排序），含复现命令与原始输出；附录 E 为修复状态，附录 F 为后续 P1–P9 安全强化与 4 项未验证缺口 | 了解「为什么这么改」「哪些还没解决」时 |
| `MIGRATION.md` | 旧版 → 当前的迁移手册：三条路径、KDF 参数绑定与换设备、密码不一致的显式报错、故障对照表、回滚边界与检查清单 | 升级/重置/换机之前必读 |

相关但不在本目录的文档：

- `README.md`：部署、API、安全架构、升级说明、本地/临时启动。
- `CHANGELOG.md`：用户可见变化与升级注意。
- `scripts/check-docs.mjs`（`npm run check:docs`）：README 与代码的一致性守卫，CI 会跑。
- `AGENTS.md`：规则集指针（正文在全局 `agents-rules` skill，项目内不留副本）。

## 添加入口

新增文档时在 `README.md` 的「项目结构」里登记，并在本表加一行，避免成为孤儿文件。
